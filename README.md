# Team10-Student-info-app

To learn Collaborative Git Workflow Using a Simple Web Application

## Student Information System

A simple web application to display student information.

### Features

- Input fields for Name, Register Number, and Programme
- Show Details button to display entered information
- Clean and responsive design

### Files

- `index.html` - Main HTML structure
- `style.css` - Styling for the application
- `script.js` - JavaScript functionality

### How to Use

1. Open `index.html` in a web browser
2. Enter student details in the form
3. Click "Show Details" to display the information

### Development

This project is for learning collaborative Git workflow using a simple web application.
